# Data license and data availability

Example data and demonstration files included in this repository are provided for academic demonstration, peer review, and reproducibility purposes only, unless otherwise stated.

Public datasets used in the manuscript, including GEO datasets, remain subject to the terms and conditions of their original data providers. This repository does not relicense third-party public datasets.

If a dataset is downloaded from GEO or another public repository, provide the accession number and original source in the README or documentation rather than treating it as original data generated by this project.
