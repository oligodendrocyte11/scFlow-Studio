# Quick Start

1. Launch scFlow Studio.
2. Click **New Project** and select a project directory.
3. Add samples from 10X folders, expression matrices, archives, or compatible Seurat RDS files.
4. Use **Check Data** to validate input files.
5. Run each analysis step from top to bottom, reviewing parameters before execution.
6. Inspect generated figures and tables in the preview panel.
7. Use the export page to collect figures, tables, h5ad files, or Seurat objects.

For a minimal test, prepare one or more 10X folders containing `matrix.mtx.gz`, `barcodes.tsv.gz`, and `features.tsv.gz`.
