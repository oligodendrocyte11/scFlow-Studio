## Availability

This build does not require activation through **2026-10-31**. Starting **2026-11-01**, a valid activation code is required. Valid device-bound activation codes issued for the same product line remain supported.

## Installation notes

- Windows 10 or Windows 11, 64-bit
- Approximately 4.72 GB installed size before project data and caches
- 16 GB RAM minimum; 32 GB or more recommended
- The installer is not digitally signed and may trigger a Windows SmartScreen warning
- Verify the SHA-256 checksum before running the installer

## Runtime

The installer includes R 4.5.2, Seurat 5.4.0, SeuratObject 5.3.0, the required R package library, and the packaged Python application environment.

## Documentation

The illustrated English manual covers installation, uninstall, interface controls, all supported data-import methods, the full 16-step workflow, a GSE250245 example, common parameters, and troubleshooting.

The matching macOS DMG will be published as a separate release so that platform-specific installation and signing information remains clear.
